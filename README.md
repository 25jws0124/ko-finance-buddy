# KO-Finance Buddy

한국에 막 들어온 외국인(D-2 유학생 · E-9 근로자)이 은행에서 겪는 절차를 **공식 출처로 대조한 규칙만으로** 안내하는 웹 서비스입니다.
비자·자격·필수서류 판정은 LLM이 아니라 규칙엔진(코드)이 하고, LLM은 사용자가 올린 한국어 문서 사진을 읽어 설명하는 역할만 맡습니다.
**근거가 없으면 답을 만들지 않습니다.** 검증되지 않은 조합은 "공식기관 확인 필요" 화면으로 정직하게 멈춥니다.

---

## 로컬에서 실행하기

### 1. Node.js 설치 확인

터미널에서:

```bash
node -v
```

`v18` 이상이면 됩니다. 없으면 https://nodejs.org 에서 LTS 버전을 설치하세요.

### 2. 패키지 설치

이 폴더를 VS Code로 연 다음, 터미널(`Ctrl` + `` ` ``)에서:

```bash
npm install
```

### 3. Gemini API 키 넣기

1. https://aistudio.google.com 접속 → 로그인 → **Get API key** → 키 복사
2. 프로젝트 루트에 `.env.local` 파일을 새로 만들고 아래 한 줄을 넣습니다.

```
GEMINI_API_KEY=여기에_복사한_키_붙여넣기
```

> `.env.local` 은 `.gitignore` 에 들어 있어서 GitHub에 올라가지 않습니다. 키가 노출되지 않습니다.
> `NEXT_PUBLIC_` 접두사를 절대 붙이지 마세요. 붙이면 키가 브라우저에 그대로 노출됩니다.

### 4. 실행

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 구조 한눈에

| 경로 | 역할 |
|---|---|
| `data/rules.json` | 출처 6건 · 규칙 6건 · 사기패턴 2건. **모든 안내 문구의 원천** |
| `lib/engine.js` | 규칙엔진. 순수 함수. LLM 호출 없음 |
| `app/api/analyze/route.js` | Gemini 호출 + 근거 없는 항목을 걸러내는 서버 필터 |
| `app/page.js` | 5개 화면 전환 상태머신 |
| `app/globals.css` | 목업에서 추출한 디자인 토큰 |

## 규칙·서류를 바꾸고 싶다면

코드를 고치지 말고 **`data/rules.json` 만** 고치세요.
화면의 "규칙 DB 5/6건" 같은 숫자도 이 파일에서 자동으로 세기 때문에, 데이터를 늘리면 숫자가 알아서 따라갑니다.

## 심사에서 보여줄 4가지 시나리오

| # | 입력 | 기대 결과 |
|---|---|---|
| A | D-2 + 이체한도 풀기 | 조건부 가능 / 준비물 3건 / 영업점 방문 필요 / 100만원 함정 경고 / KB국민은행 원문 인용 |
| B | E-9 + 급여·알바비 받을 계좌 | 조건부 가능 / 준비물 3건 / 방문 필요 |
| C | 아무 한국어 금융문서 사진 업로드 | 3블록(해야 할 일 / 돈 주의점 / 추가 확인) + 각 항목에 **문서 원문** 인용 |
| D | D-2 + 본국으로 송금하기 | **공식기관 확인 필요 (abstain)** — 오류가 아니라 설계 |
